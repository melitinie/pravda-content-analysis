# Межгодовой анализ изменений контента новостного портала «Правда»

Этот репозиторий содержит материалы исследования, посвященного анализу изменений контента онлайн-новостного портала [«Правда»](https://www.pravda.ru/) в период с 2018 по 2020 год. Проект выполнен студентами Группы 30002 (Компьютерная Лингвистика, ГИ СПБПУ).

## Цель проекта
Главная цель исследования — изучить, как менялся контент новостного портала на протяжении нескольких лет, выявить ключевые темы, тенденции и изменения в фокусе внимания редакции в различных рубрике "Общество". 

## Общий подход и задачи
Для проведения контент-анализа статей были реализованы следующие задачи:
1. **Анализ размера документов:** отслеживание динамики количества публикуемых статей и их средней длины.
2. **Анализ словарного состава:** выявление наиболее частотных лемм и оценка лексического разнообразия.
3. **Моделирование тем (Topic Modeling):** использование метода LSA (Latent Semantic Analysis) для определения доминирующих тем в разные годы.
4. **Кластеризация документов:** группировка статей с помощью алгоритма K-means для выявления смысловых границ.
5. **Кластеризация значительных лемм:** построение семантических карт ключевых слов для анализа их взаимосвязей.

## Анализ раздела «Общество» (2018–2020 гг.)
В рамках исследования раздела «Общество» за 2018–2020 годы (авторы: Кирьякова Мария, Ильина Вероника) были получены следующие выводы:

* **Динамика публикаций:** С 2018 по 2019 год портал перешел к модели более частых, но менее детализированных публикаций. В 2020 году средняя длина статьи умеренно выросла из-за необходимости освещения сложных тем (пандемия).
* **Словарный состав:** Тематика обсуждений сместилась от базовых понятий (2018) к экономическим и правовым вопросам (2019), а затем к социальным ситуациям и гражданской позиции, включая лексику, связанную с коронавирусом (2020).
* **Тематическое моделирование (LSA):** В 2018–2019 гг. доминировала тема пенсионной реформы. В 2020 году фокус резко сместился на пандемию COVID-19, дистанционное обучение и социальные выплаты.
* **Семантика:** Устойчиво выделяются кластеры, связанные с социальной поддержкой (пенсия, возраст, выплаты), семьей (семья, родитель, ребёнок) и трудом/образованием. 

## Технологии и инструменты
Проект реализован с использованием Python в среде Google Colab. Основные библиотеки:
* **Pandas** — обработка и манипуляция данными
* **Matplotlib** — визуализация данных
* **NLTK** и **spaCy** — токенизация и лемматизация текстов
* **Scikit-learn** — кластеризация (K-means) и снижение размерности
* **Gensim** — тематическое моделирование и векторные представления слов
